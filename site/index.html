O problemaThe problem

A reunião trava discutindo qual número está certo The meeting stalls arguing which number is right

Em quase toda empresa que usa dados, a mesma métrica aparece com valores diferentes em duas telas. O relatório de CRM conta clientes de um jeito, o de marketing de outro, e ninguém está errado: cada um implementou a regra na sua ferramenta. O custo não é o retrabalho — é a decisão que não sai porque o time perdeu a confiança no número. In almost every data-driven company, the same metric shows up with different values on two screens. The CRM report counts customers one way, marketing another, and neither is wrong: each implemented the rule inside its own tool. The cost isn't the rework — it's the decision that never gets made, because the team stopped trusting the number.

Alexandria resolve isso de forma estrutural. Cada métrica tem uma definição, escrita num lugar só, materializada numa camada testada e consumida de lá por todo mundo. Se duas leituras divergirem, o build quebra antes de a divergência chegar na tela. Alexandria solves it structurally. Each metric has one definition, written in a single place, materialized in a tested layer and consumed from there by everyone. If two readings diverge, the build breaks before the divergence ever reaches a screen.

ArquiteturaArchitecture

Três camadas, três responsabilidades que não se misturam Three layers, three responsibilities that never mix

A fronteira entre "o que chegou" e "o que eu fiz com ele" é o que torna um problema de dados auditável. Por isso a bronze não tem nenhum modelo dbt: ela é carregada por script e declarada como origem. The boundary between "what arrived" and "what I did to it" is what makes a data problem auditable. That's why bronze holds no dbt model at all: it's loaded by a script and declared as a source.

O teste que sustenta a promessaThe test that holds the promise up

Um dos três testes de reconciliação compara a receita e a contagem de pedidos do agregado diário — o que o dashboard desenha — contra a tabela-fato que o agente consulta. Se um join duplicar uma linha, a diferença aparece na CI, e não na frente de um executivo. One of the three reconciliation tests compares revenue and order counts in the daily aggregate — what the dashboard draws — against the fact table the agent queries. If a join duplicates a row, the gap shows up in CI, not in front of an executive.

DecisõesDecisions

As escolhas que um teste não mostra The calls a test doesn't show

Modelagem é uma sequência de decisões com trade-off. Estas são as quatro que mais mudam o resultado — e a razão de cada uma está versionada junto do código. Modeling is a sequence of trade-offs. These are the four that change the outcome the most — and the reasoning for each is versioned next to the code.

Pedidos cancelados entram na contagem de pedidos Canceled orders count as orders

Se saíssem, o denominador de todas as taxas mudaria de significado conforme o filtro aplicado — e é exatamente assim que dois relatórios passam a discordar sem que ninguém perceba. O cancelamento vira métrica própria. If they didn't, the denominator of every rate would shift meaning with each filter applied — which is exactly how two reports start disagreeing unnoticed. Cancellation becomes a metric of its own.

Recência é medida contra uma data de corte, não contra hoje Recency is measured against a cutoff date, not today

A base é histórica e fecha em agosto de 2018. Ancorar em current_date faria a carteira inteira parecer inativa e o projeto deixaria de ser reproduzível daqui a alguns anos. The dataset is historical and closes in August 2018. Anchoring on current_date would make the whole base look churned, and the project would stop being reproducible a few years from now.

A segmentação RFV vive no modelo, não na ferramenta de BI RFV segmentation lives in the model, not in the BI tool

Regra de negócio replicada em cada ferramenta é a forma mais rápida de "Campeão" significar uma coisa no relatório de CRM e outra no de marketing. Os quintis e os oito rótulos são calculados uma vez, em agg_clientes_rfv. A business rule replicated in every tool is the fastest way to make "Champion" mean one thing in CRM and another in marketing. The quintiles and the eight labels are computed once, in agg_clientes_rfv.

A deduplicação de avaliações acontece uma vez, na silver Review dedup happens once, in silver

A origem traz mais de uma avaliação para o mesmo pedido. O critério — a mais recente vence — é aplicado em stg_pedido_avaliacoes e provado por um teste de unicidade, para que nenhum relatório invente o seu próprio. The source ships more than one review per order. The tiebreaker — most recent wins — is applied in stg_pedido_avaliacoes and proven by a uniqueness test, so no report invents its own.

EsteiraPipeline

Roda inteiro na sua máquina, sem custo de nuvem Runs end to end on your laptop, at zero cloud cost

O banco é um arquivo local em DuckDB — nada de servidor, conta ou cartão. A cada push, o GitHub Actions reconstrói o projeto do zero, roda as 75 checagens e publica a documentação com o grafo de linhagem clicável: dá para partir de qualquer KPI e navegar até a coluna do CSV que o alimenta. Um teste que falha marca o commit como quebrado, com a mesma lógica de um pipeline de produção. The database is a local DuckDB file — no server, no account, no card. On every push, GitHub Actions rebuilds the project from scratch, runs the 75 checks and publishes the docs with a clickable lineage graph: you can start from any KPI and walk back to the CSV column feeding it. A failing test marks the commit as broken, with the same logic as a production pipeline.

Os dados são o dataset público de e-commerce da Olist. Quem clona o repositório e não quer baixar nada roda com uma amostra sintética gerada por script, com o mesmo schema — o projeto sobe em um comando. The data is Olist's public Brazilian e-commerce dataset. Anyone who clones the repo and would rather not download it runs on a script-generated synthetic sample with the same schema — the project comes up in one command.
